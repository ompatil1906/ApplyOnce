The token is stored only in this browser's localStorage and is sent straight from your browser to api.apify.com. It never touches the ApplyOnce server, and nothing about it is ever uploaded. The default actor is a pay-per-event Actor (about $0.001 per run plus $0.003 per email), so enrichment is billable — switch the level to format if you only want syntax checks.

Local database (durable storage)

Checking whether this server has local storage…

The database is a SQLite file on the machine running serve.py. Your browser's localStorage stays as the fast render cache, so drafts still render with the network down — the database is what survives a cleared browser profile, a new laptop, or a crash. Your Apify token is never written to it.

Send queue

Checking whether this server has a queue…

Approving here means you have read it. Nothing is transmitted by this page. When you are happy with the list, send it from a terminal, where you get a final prompt:

python3 mailer.py preview  then  python3 mailer.py send --limit 10 --send

preview is a real run with the delivery removed, so it shows exactly which addresses would be skipped and why — role addresses, unsubscribes, unresolved {first_name} placeholders, and the daily cap. Nothing sends unless you add --send and confirm the prompt.
